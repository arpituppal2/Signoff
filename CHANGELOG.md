# Changelog

All notable changes to Signoff are documented here. Dates are `YYYY-MM-DD`.

## [1.1.1] - 2026-07-30

### Changed
- Documentation now accurately states that every signoff is generated by an on-device model at request time. The README previously described a "curated phrase pool of 180+ signoffs loaded from JSON" and listed a `Pool/` resources directory and a `PhrasePoolLoader` step in the architecture diagram — none of which ever existed in the shipped code. The descriptions were residual copy from a pre-1.0 design and have been removed so the docs match what the app actually does (generation only, no pre-written fallback).
- Corrected the minimum-OS label from "Sequoia or later" to "Tahoe or later." macOS 26 is Tahoe; Sequoia is macOS 15.
- Replaced a broken link to a non-existent `CONTRIBUTING.md` with an "open an issue first" note.

### Internal
- Bumped the app bundle's marketing version (`CFBundleShortVersionString`) from `1.0` to `1.1.1` so the build label matches the release series.
